## Changes affecting aix

OpenCode updated from 1.18.29 to 1.18.34. Changes evaluated across releases 1.18.30 through 1.18.34:

- **Session and Parent-Session Identity Headers**: Added namespaced identity headers sent with model requests to track session parentage (v1.18.34).
   - aix status: no change needed. This is an internal HTTP transport enhancement for OpenCode.
- **MCP browser launch error reporting**: Improved error reporting when MCP browser launcher processes exit immediately (v1.18.33).
   - aix status: supported. Aix configures standard MCP commands in `.opencode/mcp.json`.
- **ACP Session Boundaries**: Restored ACP session model, effort, mode, and reasoning chunk boundaries when loading, resuming, or forking sessions (v1.18.31).
   - aix status: no change needed. This is an internal runtime fix for ACP session state persistence.
- **Provider Models and System Prompts**: Added the Astra system prompt for GPT-6 models, Bedrock DeepSeek model ID preservation, and reasoning effort controls (v1.18.30).
   - aix status: no change needed. Model routing and provider SDK integrations do not alter local workspace files.
- **Configuration, Rules, Skills, and MCP Paths**: OpenCode continues to use `.opencode/config.json`, `.opencode/rules/*.md`, `AGENTS.md`, `.opencode/skills/`, and `.opencode/mcp.json`.
   - aix status: already supported. Aix maintains native configuration for all OpenCode surfaces.

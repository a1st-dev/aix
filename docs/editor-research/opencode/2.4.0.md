## Changes affecting aix

- OpenCode v2 uses native `mcp.servers`, inverse `disabled`, split timeouts and snake-case OAuth
  fields. The release says it probes for a newer protocol by default, while the live guide
  describes legacy as the default.
   - aix status: Addressed. aix handles native registrations and uses an explicit protocol only when configured. The tagged schema describes auto as the 2.4.0 default.
- OpenCode shipped MCP events and automations, and plugins following a version range now update
  and reload on a schedule.
   - aix status: No change needed. OpenCode owns automation and plugin update behavior. Existing
     pins and ranges should be preserved.

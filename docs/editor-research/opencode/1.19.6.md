## Changes affecting aix

- The v1 editor now offers an upgrade to v2 and preserves local settings. The v2 migration docs
  describe native configuration changes and state that supported v1 fields normalize in memory.
   - aix status: Addressed. aix reads mixed v1 and v2 files and preserves their native layout and unrelated settings.
- Version 1 and version 2 plugin APIs differ.
   - aix status: Addressed in the MCP guide. The registered plugin must support the installed OpenCode runtime.

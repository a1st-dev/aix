## Changes affecting aix

- The v1 editor now offers an upgrade to v2 and preserves local settings. The v2 migration docs
  describe native configuration changes and state that supported v1 fields normalize in memory.
   - aix status: Follow-up needed. Test native v2 import, mixed layouts, and preservation on
     install. Keep v1 output compatible with supported v1 clients.
- Version 1 and version 2 plugin APIs differ.
   - aix status: Follow-up needed. Document the runtime version requirement for registered
     packages. An aix plugin registration cannot port its implementation.

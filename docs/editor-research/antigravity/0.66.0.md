## Changes affecting aix

- Gemini CLI 0.66.0 added opt-in private network endpoint support for MCP OAuth flows, resolved environment variable placeholders in settings after `.env` loading, and added `keys` array support for custom keybindings.
   - aix status: supported. aix writes standard MCP server definitions in `~/.gemini/settings.json` and respects environment variables.
- Gemini CLI 0.66.0 refactored execution scheduling to emit tool call groups directly and improved terminal UI synchronization and buffer flickering.
   - aix status: no change needed. Internal execution engine and TUI rendering refactors.
- Gemini CLI 0.66.0 preserved user-level `~/.gitconfig` settings in shell execution environments and suppressed interactive SSH/credential prompts.
   - aix status: no change needed. Runtime shell environment hardening.
- Workflows deprecation in Antigravity (effective November 1, 2026, transitioning to `.agents/skills/`) remains active and was previously addressed in aix on 2026-10-01.
   - aix status: supported. Antigravity prompt strategy converts prompts into `.agents/skills/{name}/SKILL.md`.

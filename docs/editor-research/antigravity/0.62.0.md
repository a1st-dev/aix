## Changes affecting aix

Google Antigravity / Gemini CLI updated from 0.58.0 to 0.62.0. Changes evaluated across releases 0.59.0 through 0.62.0:

- **Workflows deprecation**: Standalone Workflows (`.agents/workflows/*.md`) were deprecated in favor of standard Agent Skills (`.agents/skills/{name}/SKILL.md`) with retirement scheduled for November 1, 2026.
   - aix status: already addressed (see `docs/editor-research/antigravity/workflows-deprecation.md` on 2026-10-01). Prompts are converted into Agent Skills under `.agents/skills/{name}/` via `installPromptsAsSkills`.
- **Core Security Hardening**: Enhanced protection against prompt injection attacks via build file modifications and untrusted flags; hardened filesystem boundaries and isolated runtime state (#29250, #29214).
   - aix status: supported. Aix rules and skills follow secure local file standards and avoid untrusted argument injection.
- **AgentLoopContext State Preservation**: Guaranteed internal state properties within `AgentLoopContext` are fully preserved during spread operations (#29335).
   - aix status: no change needed. This is an internal runtime fix in the Gemini CLI agent loop.
- **MCP Tool Call Formatting in ACP**: Formatted MCP tool call titles as structured signatures and segregated explanations; emitted `tool_call` updates prior to `request_permission` in ACP mode (#29341, #29439).
   - aix status: already supported. Aix MCP configurations continue to export standard tool definitions compatible with ACP servers.
- **Rules and Skills discovery paths**: Antigravity continues discovery from `.agents/rules/*.md`, `GEMINI.md`, `AGENTS.md`, and `.agents/skills/{name}/SKILL.md`.
   - aix status: already supported. Aix natively supports `.agents/rules/`, `.agents/skills/`, and `AGENTS.md`.

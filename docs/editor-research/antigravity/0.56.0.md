## Changes affecting aix

No aix change is needed for this range.

Gemini CLI shipped 0.52.0 (2026-07-22), 0.53.0 (2026-07-28), 0.54.0 (2026-08-06),
0.55.1 (2026-08-11), and 0.56.0 (2026-08-19). The changelog index and the per-release
notes for that range are dominated by work on the project's own maintenance robots and
release infrastructure: caretaker triage services, an LLM triage orchestrator, the
Antigravity PR-generator agent, and Cloud Run deployment plumbing. None of that is
shipped configuration.

Nothing in the range changes `settings.json` keys, `GEMINI.md` or `AGENTS.md` context
file handling, the MCP server block, extensions, custom command files, skills, or hooks.

The entries closest to anything aix owns:

- 0.52.0: "fix(core): simplify plan mode write policy to support relative paths".
   - aix status: no change needed. This is the agent's own write-permission policy in
     plan mode, not a config schema aix generates.
- 0.53.0: "fix(a2a-server): enforce workspace trust and task isolation to prevent RCE".
   - aix status: no change needed. Server-side hardening of the agent-to-agent server.
     It does affect when project config is trusted, the same way the equivalent Claude
     Code and Cursor trust changes do, but does not change what aix writes.
- 0.53.0 added an eval coverage report command, and 0.54.0 added session ID rotation on
  model fallbacks.
   - aix status: no change needed. Neither is a config surface.

Note on version numbering: `docs/changelogs/latest.md` in the repository still documents
0.55.1, while npm's `latest` tag and the GitHub releases both give 0.56.0 (released
2026-08-19). The 0.56.0 release body contains only a compare link. This document is
filed under the npm release, 0.56.0, and the gap is why it carries no 0.56-specific
bullets.

## Baseline evidence

- `packages/core/src/editors/adapters/gemini.ts` and
  `packages/core/src/editors/strategies/gemini/` hold the current Gemini output.
- The test "preserves user-authored keys in .gemini/settings.json across installs" in
  `packages/core/src/__tests__/editors/adapters.test.ts` covers unknown-key preservation,
  which is what protects aix against every settings key added in this range.
- `packages/core/src/editors/strategies/gemini/hooks.ts` owns the Gemini hook output,
  including the `sequential` group flag, unchanged by this range.

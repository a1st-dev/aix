## Changes affecting aix

- Claude Code 2.1.277 added native support for reading `AGENTS.md` project instruction files.
  When an `AGENTS.md` file is present in a repository or directory tree and no `CLAUDE.md` is
  present, Claude Code automatically reads `AGENTS.md` as its source of project instructions.
  If both files exist, `CLAUDE.md` takes precedence unless configured otherwise.
   - aix status: addressed 2026-09-24. In `packages/schema/src/editor-support.ts`, the
     `agents-md` feature for `claude-code` was updated from `unsupported` to `native`.
     `ClaudeCodeAdapter.detect()` was expanded to detect projects containing `CLAUDE.md`.
     In addition, legacy fallback `CLAUDE.md` files whose sole content is an import or link
     to `AGENTS.md` (e.g. `@AGENTS.md`) are detected with an informational notice that
     `CLAUDE.md` is now redundant and can be removed.

## Changes affecting aix

- Plugin manifests can declare a Claude Code version range in `engines["claude-code"]`.
   - aix status: No change needed. aix enables plugins and Claude reads compatibility from their
     source manifests.
- Project MCP approvals match the exact server name, and untrusted workspaces have less
  authority over hooks and plugins.
   - aix status: No change needed. aix writes standard server keys and leaves trust and
     approvals to Claude.

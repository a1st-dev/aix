## Changes affecting aix

- Claude Code 2.1.318 expanded `deniedMcpServers` in configuration to block Anthropic-provided servers by matching upstream URLs, alongside server name blocking.
   - aix status: no change needed. aix does not configure or manage `deniedMcpServers` access control policies.
- Claude Code 2.1.317 added `onFailure: "block"` for Agent SDK hook callbacks, so a callback that fails blocks the action instead of letting it run.
   - aix status: no change needed. This applies to the Agent SDK programmatic API rather than `.claude/settings.json` hook command declarations.
- Claude Code 2.1.314 added `permissions.blockWritesOutsideWorkingDirectories` setting, causing file edit and write tools to reject paths outside working directories in every permission mode.
   - aix status: supported. aix writes project configuration within project directories and respects workspace boundaries.
- Claude Code 2.1.287 introduced Claude Mods, enabling plugins to modify deeper runtime behaviors (e.g. `/plugin enable cc-plugin-you-should-know@builtin`).
   - aix status: supported. `ClaudeCodePluginsStrategy` manages enabled plugins in `settings.json` and marketplace installations.
- Claude Code 2.1.285 added `claude plugin configure <plugin>` for inspecting and setting plugin configuration, and added `<server>.<key>=<value>` plugin arguments.
   - aix status: supported. Managed plugin configurations are emitted into `.claude/settings.json`.

## Baseline evidence

- `packages/core/src/editors/adapters/claude-code.ts` wires Claude Code rules, commands, MCP, skills, hooks, plugins, and marketplaces.
- `packages/schema/src/editor-support.ts` documents Claude Code integration capabilities.

## Changes affecting aix

- Sandboxed Bash uses the normal approval flow by default. Scheduled tasks and loops can require
  approval for skills that declare hooks or allowed tools.
   - aix status: No change needed. Claude applies these permissions at runtime.
- Claude validates plugin paths more strictly and moves extracted MCP bundles to its plugins
  directory.
   - aix status: No change needed. Claude resolves bundled content for plugins enabled by aix.
- A marketplace ref can pin a full commit ID reachable from a branch or tag.
   - aix status: Follow-up needed. The marketplace importer reduces Git and GitHub sources to
     strings and drops their separate `ref` field. Preserve the pin and document the minimum
     Claude version.

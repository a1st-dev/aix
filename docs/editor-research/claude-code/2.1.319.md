## Changes affecting aix

- MCP tool tasks can run in the background. With the Bash sandbox on, nested skills load from
  their own directory at launch or after changing to it.
   - aix status: No change needed. Scheduling and nested discovery are editor behavior. aix uses
     the selected scope's skill path.
- PostToolUse hooks can still finish after a user interrupts a tool call, and marketplaces from
  added folders require separate trust.
   - aix status: No change needed. Claude handles hook invocation and folder trust.

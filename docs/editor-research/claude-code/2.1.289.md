## Changes affecting aix

Claude Code updated from 2.1.277 to 2.1.289. Changes evaluated across releases 2.1.278 through 2.1.289:

- **Claude Mods plugin extension mechanism**: Allows plugins to modify agent behavior more deeply.
   - aix status: no change needed. Aix manages MCP servers, rules, skills, agents, and hooks; Claude Code plugins are managed via Claude Code plugin commands and do not alter existing aix configuration surfaces.
- **MCP URL Prompts and Elicitation Protocol**: Added support for URL-based prompts from MCP servers implementing the 2025-11-25 MCP specification (`bareElicitationCapability`).
   - aix status: already supported. Aix MCP configuration supports standard stdio, SSE, and HTTP MCP servers.
- **MCP server `alwaysLoad: false` configuration**: Added an optional `alwaysLoad` property for MCP servers to defer loading tools until explicitly called.
   - aix status: already supported. Aix preserves arbitrary server configuration properties when writing `.mcp.json` or `.claude/mcp.json`.
- **Teammate agent spawning**: Added `agent.spawn` tool for delegating tasks to teammate agents.
   - aix status: no change needed. Subagent spawning is an internal execution capability of Claude Code.
- **Path-scoped rules loading fix**: Fixed an issue where path-scoped rules in `.claude/rules/` did not load properly upon file write or edit.
   - aix status: supported. Aix writes path-scoped and general rules to `.claude/rules/*.md`, which now reliably apply on file edits.
- **Native AGENTS.md support**: Confirmed stable native support for `AGENTS.md` introduced in 2.1.277.
   - aix status: already supported. Aix documents and utilizes native `AGENTS.md` support for Claude Code.

## Changes affecting aix

- Devin Desktop 3.11.212 introduced the new Agent Window matching app.devin.ai, with multi-session layouts, workspace grouping, file tree, changes viewer, and customizable appearance.
   - aix status: no change needed. Front-end UI enhancement for Devin Desktop.
- Devin Desktop 3.10.35 enabled MCP servers passed by ACP clients in `session/new` / `session/load` to be usable by the agent and listed in `/mcp`, including HTTP and SSE MCP servers.
   - aix status: supported. `WindsurfMcpStrategy` manages global MCP servers in `~/.codeium/windsurf/mcp_config.json`.
- Devin Desktop 3.10.31 reinforced Restricted Mode security by blocking restricted workspace settings in nested object form in addition to dotted paths (CVE-2026-81376).
   - aix status: supported. aix-generated configurations use standard safe schemas.
- Devin Desktop 3.9.19 retired legacy Cascade entry points (workflow commands, annotations, etc.) in favor of Devin Local. Configured MCP servers can now be @-mentioned directly in chats.
   - aix status: supported. `WindsurfAdapter` uses Devin Local aliases and standard paths (`.windsurf/rules/`, `~/.codeium/windsurf/mcp_config.json`, `.windsurf/hooks.json`).

## Baseline evidence

- `packages/core/src/editors/adapters/windsurf.ts` manages Windsurf / Devin Desktop rules, workflows, and MCP configuration.
- `packages/schema/src/editor-support.ts` documents Windsurf features and known caveats.

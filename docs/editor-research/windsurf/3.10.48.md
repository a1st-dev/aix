## Changes affecting aix

Windsurf / Devin Desktop updated from 3.8.20 to 3.10.48. Changes evaluated across releases 3.9.19 through 3.10.48:

- **Cascade Legacy Clean-Up**: Removed deprecated Cascade legacy entry points and legacy workflow annotations in favor of Devin Local / ACP execution architecture (v3.10.23).
   - aix status: supported. Aix configurations interact with standard `.windsurf/rules/`, `.codeium/windsurf/mcp_config.json`, and native Agent Skills rather than deprecated Cascade annotations.
- **ACP Client MCP Server Passthrough**: MCP servers passed by the ACP client during `session/new` and `session/load` are available to the agent and listed under `/mcp` (v3.10.35).
   - aix status: already supported. Aix writes global and project MCP configs to `.codeium/windsurf/mcp_config.json` and `.mcp.json`.
- **Language Server CPU/Memory Profiles**: Added language server resource management and profile switching (v3.10.48).
   - aix status: no change needed. This is an internal runtime performance optimization.
- **Rules, Skills, and Prompts Paths**: Windsurf continues to load rules from `.windsurf/rules/*.md`, `AGENTS.md`, and Agent Skills from `.windsurf/skills/` and `.agents/skills/`.
   - aix status: already supported. Aix maintains native configuration for all Windsurf paths.

## Baseline evidence

- `packages/schema/src/editor-support.ts` documents Windsurf rules, prompt-to-skill conversion, and MCP configuration.
- `packages/core/src/editors/adapters/windsurf.ts` defines the Windsurf adapter and handles file operations.
- `packages/core/src/editors/strategies/windsurf/rules.ts` formats `.windsurf/rules/*.md`.
- `packages/core/src/editors/strategies/windsurf/mcp.ts` formats `.codeium/windsurf/mcp_config.json`.

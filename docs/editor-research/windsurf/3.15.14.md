## Changes affecting aix

- Desktop enforces managed sign-in policy from `system.json` and offers skill mentions after
  existing text in Devin Local conversations.

     skill definitions.
- Devin Local documents project and user MCP files at `.devin/mcp_config.json` and
  `~/.config/devin/mcp_config.json`. aix writes `~/.codeium/windsurf/mcp_config.json`.
  Devin Local explicitly reads legacy project Windsurf skills and rules.
   - aix status: Addressed in the support matrix. A scratch Devin CLI loaded legacy project rules and skills, user rules, and user MCP. A matching native project MCP name took precedence.

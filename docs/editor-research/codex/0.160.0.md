## Changes affecting aix

Codex updated from 0.153.4 to 0.160.0. Changes evaluated across releases 0.154.0 through 0.160.0:

- **Pre-registered OAuth client secrets for MCP**: Added `--oauth-client-secret` support for connecting to MCP servers requiring pre-registered credentials (#47891).
   - aix status: already supported. Aix MCP configuration supports generic environment and arguments configurations for MCP servers.
- **Native POSIX spawning for command hooks**: Switched command hook execution to native POSIX spawning (#47610).
   - aix status: supported. Aix hooks generated for Codex remain POSIX-compatible shell commands.
- **Subagents retain pending environments**: Subagents spawned in Codex inherit pending environment configurations (#49075).
   - aix status: supported. Subagent configuration and execution inherit workspace environment variables correctly.
- **Removal of `tui.prompt_suggestions` and `plugin-creator` skill**: Deprecated prompt suggestions in TUI and removed the bundled `plugin-creator` skill (#48621, #48604).
   - aix status: no change needed. Aix does not configure `tui.prompt_suggestions` or rely on the bundled `plugin-creator` skill.
- **Rules and Skills discovery**: Codex continues to discover rules from `.codex/rules/*.md` and `AGENTS.md`, and Agent Skills from `.agents/skills/{name}/SKILL.md`.
   - aix status: already supported. Aix manages `.codex/rules/` and converts prompts to Agent Skills under `.agents/skills/`.

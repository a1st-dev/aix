## Changes affecting aix

- Codex 0.166.0 and 0.165.0 added native Google Cloud Vertex AI provider support (`model_provider = "gcp"`) and enabled memory v2 by default with external-agent memory import.
   - aix status: supported. aix configures `AGENTS.md` instructions and MCP servers in `config.toml`, which are read across provider configurations.
- Codex 0.164.0 added numbered `/presets` slots (slots 1-10) for saving and triggering reusable prompts via keyboard menu.
   - aix status: no change needed. Codex continues to convert aix prompts into instruction-only Agent Skills under `.agents/skills/{name}/SKILL.md` (via `installPromptsAsSkills`). Numbered `/presets` are interactive TUI slots rather than workspace configuration files.
- Codex 0.161.0 introduced interactive `/mcp login <name>` and restricted enterprise MCP authentication with fail-closed refresh.
   - aix status: supported. `CodexMcpStrategy` formats standard `[mcp_servers.<name>]` entries in `config.toml`. Authentication tokens are managed by the Codex runtime.
- Codex 0.158.0 improved POSIX command hook spawning and added support for OAuth client secrets in `codex mcp add --oauth-client-secret`.
   - aix status: supported. `CodexHooksStrategy` generates native hook entries in `hooks.json` / `config.toml`.

## Baseline evidence

- `packages/core/src/editors/strategies/codex/mcp.ts` formats Codex `config.toml` MCP server tables.
- `packages/core/src/editors/strategies/codex/hooks.ts` manages Codex hook formatting and event mapping.
- `packages/core/src/editors/adapters/codex.ts` converts prompts to skills and wires strategies.
- `packages/schema/src/editor-support.ts` documents Codex capabilities and profiles.

## Changes affecting aix

- Copilot accepts JSONC at both project MCP paths.
   - aix status: Supported. aix imports both paths through its JSONC parser and writes
     compatible JSON.
- Copilot supports process-wide environment settings and warns when a plugin and a standalone
  MCP server share an endpoint.
   - aix status: No change needed. Copilot owns global process settings and duplicate warnings.
     aix manages per-server or per-hook settings.
- Copilot added a build-time schema for extension manifests.
   - aix status: No change needed. aix manages activation and marketplace settings. Extension
     authors own manifest content.

## Changes affecting aix

- Copilot moves more legacy XDG home settings and customizations into `~/.copilot`. GitHub
  documents `COPILOT_HOME` as an override.
   - aix status: Addressed. aix writes to the active Copilot CLI home and retains per-item fallback imports and removals from the earlier aix directory.
- Copilot exposes `COPILOT_HOOK_DEPTH` to command hooks and `COPILOT_SESSION_CWD` to local MCP
  and LSP launch config.
   - aix status: No change needed. Copilot supplies both variables at runtime.
- Plugin rules accept comma-separated glob strings and Copilot expands home-relative skill
  paths.
   - aix status: No change needed. Matching and discovery are native Copilot behavior.

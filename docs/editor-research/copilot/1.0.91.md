## Changes affecting aix

GitHub Copilot CLI updated from 1.0.83 to 1.0.91. Changes evaluated across releases 1.0.84 through 1.0.91:

- **Custom agents repository instruction opt-in**: Custom agents can opt into repository instruction files (`AGENTS.md`, `copilot-instructions.md`, `CLAUDE.md`) by setting `include-custom-instructions: true` in their frontmatter (v1.0.86).
   - aix status: supported. In `packages/core/src/editors/adapters/copilot.ts`, custom agents pass through arbitrary frontmatter specified in `agent.editor.copilot`, allowing developers to set `include-custom-instructions: true`. `packages/schema/src/editor-support.ts` documents this capability under Copilot agent support.
- **Support for Claude Code rule files**: Copilot added support for Claude Code rule files in `.claude/rules` as custom instructions (v1.0.90).
   - aix status: supported. Aix manages native Copilot instructions at `.github/instructions/*.instructions.md` while recognizing `.claude/rules/` for multi-editor interoperability.
- **Hook execution working directory fix**: Hook commands without an explicit `cwd` run in the project root instead of the session's current directory, ensuring repo-relative hook scripts resolve reliably from subdirectories (v1.0.87).
   - aix status: supported. Aix hook definitions rely on project root execution.
- **Namespaced custom skills discovery**: Copilot supports namespaced custom skills and ignored skill directories during discovery (v1.0.87).
   - aix status: already supported. Aix installs skills to `.github/skills/{name}/` and `.agents/skills/{name}/`.
- **Pre-registered OAuth client scopes for MCP**: MCP pre-registered OAuth clients honor configured `oauthScopes` (v1.0.90).
   - aix status: already supported. Aix writes MCP server configurations to `.mcp.json` preserving custom properties.
- **Copilot sandbox CA management**: Added `copilot sandbox ca` command suite for certificate management (v1.0.91).
   - aix status: no change needed. Sandbox proxy certificate administration is handled interactively via CLI commands.

## Baseline evidence

- `packages/schema/src/editor-support.ts` documents Copilot instructions, prompt files, agents, MCP configuration, and skills.
- `packages/core/src/editors/adapters/copilot.ts` defines the Copilot adapter, detecting `.github/` configurations and wiring markdown agents.
- `packages/core/src/editors/strategies/copilot/rules.ts` manages `.github/instructions/*.instructions.md`.
- `packages/core/src/editors/strategies/copilot/hooks.ts` manages `.github/hooks/hooks.json`.

## Changes affecting aix

- Copilot skips session-end hooks when no prompt was submitted and clarifies that managed hooks
  still run with `disableAllHooks`.
   - aix status: No change needed. Copilot implements both behaviors.
- MCP forms can save servers requiring custom authentication headers and preserve comma-
  separated environment values.
   - aix status: Supported. aix already serializes headers and environment values as strings.
- An empty Claude hook matcher works as a wildcard, and invalid Agent Plugins manifests yield
  install diagnostics.
   - aix status: No change needed. Copilot owns compatibility loading and manifest validation.

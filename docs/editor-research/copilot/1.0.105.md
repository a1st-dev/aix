## Changes affecting aix

- Copilot 1.0.102 added support for plugin marketplaces from `git-subdir` sources and long plugin descriptions.
   - aix status: supported. aix generates GitHub Copilot plugin and marketplace catalog entries.
- Copilot 1.0.101 added the `assistedApprovalInstructions` setting to guide Assisted Permissions confirmation decisions, and allowed custom agents declaring tool aliases `search`, `web`, or `todo` to receive matching tools.
   - aix status: supported. `CopilotAgentsStrategy` creates custom agent files under `.github/agents/*.md` with supported tool frontmatter.
- Copilot 1.0.84 added automatic application of path-specific instruction files in repository root `.github/instructions/*.instructions.md` when files matching target paths are read or edited.
   - aix status: supported. `CopilotRulesStrategy` writes `.github/instructions/*.instructions.md` rule files.
- Copilot 1.0.84 updated skill `allowed-tools` rules to keep commas within arguments rather than splitting on commas.
   - aix status: supported. aix emits standard YAML frontmatter for skills.

## Baseline evidence

- `packages/core/src/editors/adapters/copilot.ts` integrates Copilot rules, instructions, skills, agents, and hooks.
- `packages/core/src/editors/strategies/copilot/rules.ts` manages `.github/instructions/`.
- `packages/core/src/editors/strategies/copilot/agents.ts` manages `.github/agents/`.
- `packages/schema/src/editor-support.ts` documents Copilot features.

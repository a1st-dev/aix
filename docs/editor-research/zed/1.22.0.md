## Changes affecting aix

Zed updated from 1.18.1 to 1.22.0. Changes evaluated across releases 1.19.0 through 1.22.0:

- **Subagent model parameter in `spawn_agent`**: Added an optional `model` parameter to `spawn_agent` to choose a specific model for that subagent spawn instead of using configured defaults (v1.22.0, #64498).
   - aix status: supported. Subagents in aix define `model` in their configuration, which aligns with Zed's model override capabilities.
- **Subagent Compaction**: Enabled automatic context compaction for subagents (v1.22.0, #64135).
   - aix status: no change needed. This is an internal runtime feature in Zed's agent execution loop.
- **Settings inheritance syntax (`"..."`)**: Added support for `"..."` in `edit_predictions.disabled_globs`, `read_only_files`, `file_scan_inclusions`, and `hidden_files` so project settings extend inherited patterns without repeating them (v1.22.0, v1.21.0).
   - aix status: already supported. Aix writes clean, standard JSON to `.zed/settings.json`.
- **System idle sleep prevention**: Added `agent.prevent_idle_sleep` setting, enabled by default, to prevent system sleep during long-running agent threads (v1.21.0, #53130).
   - aix status: no change needed. This is an editor runtime configuration option.
- **Rules, Prompts, and MCP surfaces**: Zed continues to discover rules from `.zed/rules/` and `AGENTS.md`, prompts converted to Agent Skills in `.agents/skills/{name}/`, and MCP configuration in `.zed/settings.json` under `context_servers`.
   - aix status: already supported. Aix manages `.zed/settings.json`, `.agents/skills/`, and `AGENTS.md`.

## Baseline evidence

- `packages/schema/src/editor-support.ts` documents Zed integration features including rules, prompt-to-skill conversion, and context servers.
- `packages/core/src/editors/adapters/zed.ts` detects Zed workspaces and manages `.zed/settings.json` and skills.
- `packages/core/src/editors/strategies/zed/rules.ts` formats `.zed/rules/` and `AGENTS.md`.
- `packages/core/src/editors/strategies/zed/mcp.ts` formats context server entries in `.zed/settings.json`.

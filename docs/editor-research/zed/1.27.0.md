## Changes affecting aix

- Zed 1.27.0 improved Agent Panel performance and memory consumption by deferring tool-call diff rendering and Markdown parsing until threads are viewed.
   - aix status: no change needed. UI performance optimization.
- Zed 1.26.2 improved ACP configuration defaults to apply to new conversations, preserving existing conversation settings, and fixed JSON completion ordering in `settings.json`.
   - aix status: supported. `ZedMcpStrategy` formats `context_servers` in `.zed/settings.json`.
- Zed 1.25.2 enabled context compaction and session notices for external agents via ACP, and added support for Display P3 color space.
   - aix status: no change needed. Runtime ACP protocol enhancement.
- Zed 1.21.3 added support for `"..."` wildcard inheritance in `read_only_files` settings so project configs can extend inherited read-only patterns.
   - aix status: supported. aix preserves custom `settings.json` keys outside `context_servers`.
- Zed 1.19.2 resolved an issue where settings migration prompts appeared unnecessarily when context servers were configured with only a `url`.
   - aix status: supported. `ZedMcpStrategy` emits compliant HTTP/SSE and command context server entries.

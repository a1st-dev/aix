## Changes affecting aix

- Zed 1.18.1 fixed an issue where integrated terminal inputs were dropped on Windows for
  certain keyboard layouts, and prevented `goToDefinition` from navigating out-of-worktree.
   - aix status: no change needed. Core editor stability bugfixes.
- Zed 1.18.0 refreshed Markdown preview styling and added persistent File Finder history
  across workspace sessions.
   - aix status: no change needed. UI and preview enhancements.
- Zed 1.18.0 fixed the inline assistant becoming unresponsive when an LLM model emitted
  reasoning blocks prior to initiating tool calls.
   - aix status: no change needed. Assistant runtime execution fix.
- Zed 1.17.2 introduced tabular data preview support and enabled low reasoning effort
  configurations for DeepSeek V4 Flash and Pro models.
   - aix status: no change needed. Editor capability improvements.
- Zed's assistant configuration, context server schema (`context_servers` in
  `settings.json`), and rules loading (`.zed/rules.md`) remain stable and unchanged.
   - aix status: supported. `packages/core/src/editors/adapters/zed.ts` targets
     `.zed/settings.json` context servers and rules files.

## Baseline evidence

- `packages/core/src/editors/strategies/zed/mcp.ts` formats context server entries in

- `packages/core/src/editors/strategies/zed/rules.ts` formats Zed rules.

## Changes affecting aix

No aix change is needed for this range.

Cursor continues its unversioned changelog format since 3.11 (2026-07-10). Per the filing
convention documented in `skills/editor-release-research/SKILL.md`, this document is dated
`2026-11-04.md` and preserves `editor_version: "3.11"`.

The changes published on Cursor's changelog since the previous research pass on 2026-09-07 are:

- Agent SDK (2026-10-20): Released Agent SDK for building, testing (`agent-sdk dev`), and
  deploying (`agent-sdk deploy`) custom bots and background agents to Cursor cloud infrastructure.
   - aix status: no change needed. Developer SDK for hosted cloud agents; does not alter local
     workspace configuration formats.
- Cloud Agent Canvases and Environments (2026-10-16): Introduced interactive canvases and
  environment management for Cursor cloud agents.
   - aix status: no change needed. Cloud agent UI feature.
- Origin App Marketplace (2026-10-13): Launched integrations with over 20 apps for deployments,
  CI, code review, security, and project management on Origin.
   - aix status: no change needed. Origin web platform marketplace; local
     `.cursor-plugin/marketplace.json` team catalogs remain stable.
- Remote control for local agents (2026-10-06): Enabled viewing and replying to local agents running
  on desktop from the Cursor iOS app.
   - aix status: no change needed. Companion mobile app remote control feature.
- Rollouts and Security Review (2026-09-23): Launched cloud-managed bots for deployment health
  monitoring and PR security review.
   - aix status: no change needed. Cloud review bot services.
- Local configuration formats (`.cursor/rules/*.mdc`, `.cursor/commands/*.md`, `.cursor/mcp.json`,
  `.cursor/hooks.json`, `.cursor/skills/`, and `.cursor/agents/*.md`) remain stable.
   - aix status: supported.

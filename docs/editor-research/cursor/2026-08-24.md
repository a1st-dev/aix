already covered by `3.11.md`. This document is filed by date instead of version because
there is no new version to name. See the note at the end for the convention.

## Filing convention

Cursor stopped attaching version numbers to changelog entries after 3.11. Research for an
editor in that state is filed as `<YYYY-MM-DD>.md`, with `editor_version` holding the
last version the editor did publish. The alternative, inventing a version number or
rewriting the previous version's document, would either fabricate a fact or destroy the
record of when something was checked. The rule is written down in the
`editor-release-research` skill.

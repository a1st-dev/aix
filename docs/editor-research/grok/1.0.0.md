## Changes affecting aix

- Grok Build CLI stores MCP configuration in TOML format (`.grok/config.toml` for project scope, `~/.grok/config.toml` for user scope) under `[mcp_servers.<name>]`.
   - aix status: supported via GrokMcpStrategy with both stdio and HTTP support.
- Grok Build CLI reads rules from `.grok/rules/*.md` and user rules from `~/.grok/rules/*.md`, alongside native discovery of `AGENTS.md`.
   - aix status: supported via GrokRulesStrategy.
- Grok Build CLI exposes custom slash commands in its interactive TUI through Agent Skills.
   - aix status: supported via prompt-to-skill conversion into `.grok/skills/prompt-{name}/`.
- Grok Build CLI supports lifecycle hooks in `.grok/hooks.json` and `~/.grok/hooks.json`.
   - aix status: supported via GrokHooksStrategy.

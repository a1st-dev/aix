## Changes affecting aix

Grok Build CLI updated from 1.0.0 to 1.0.43. Changes evaluated across releases 1.0.1 through 1.0.43:

- **MCP Minimal-Mode Tool Prompts**: Fixed prompt generation when exposing MCP tools in minimal context mode (v1.0.43).
   - aix status: supported. Aix MCP configuration writes valid TOML entries in `.grok/config.toml` and user configuration.
- **Seatbelt Sandboxing on macOS**: Integrated Apple Seatbelt sandboxing profile constraints for CLI execution subshells (v1.0.38).
   - aix status: no change needed. This is an OS sandbox layer managed by the Grok binary.
- **Concurrent File Modification Guard**: Serialized concurrent tool execution when writing to identical target paths (v1.0.35).
   - aix status: no change needed. Internal execution safety improvement in the Grok tool loop.
- **Interactive Context Window Command**: Added `/context-window` slash command for inspecting active token distributions (v1.0.29).
   - aix status: no change needed. Interactive TUI utility command.
- **Configuration Surfaces**: Rules continue at `.grok/rules/*.md`, `AGENTS.md`, MCP servers in `.grok/config.toml`, hooks in `.grok/hooks.json`, and prompts converted to Agent Skills in `.grok/skills/`.
   - aix status: already supported. Aix natively supports all Grok CLI configuration surfaces.
